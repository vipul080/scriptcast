Ten lines in, video out

Point at things the way you'd describe them: button text, field labels, any visible text. If two things match, scriptcast picks the best one and tells you.

  • Check in seconds: scriptcast check runs every step without recording.
  • Apps behind a login: sign in off camera, passwords from environment variables.
  • Nothing else to install: ffmpeg, fonts and the browser come with it.
url: http://localhost:3000
steps:
  - say: Create a report in seconds
  - click: New report
  - type: { into: Report name, text: Weekly users }
  - click: Email me every Monday
  - click: Create report
  - say: It's live right away

# npx scriptcast record demo.yml

Prefer buttons? Use the studio.

Run npx scriptcast studio and press Record my clicks. Use your site normally and every click and keystroke becomes a step. Add captions, press Make video, download.

Phone demos, too

Add device: iphone and scriptcast records your site's mobile layout inside a phone frame, with taps shown as touches. You get a vertical video ready for Reels, Shorts or your app's landing page.

  • Window styles: light, dark, or no window at all.
  • Backgrounds: seven gradients or any color.
  • GIF or MP4: sized for READMEs or social posts.

Keep it fresh with GitHub Actions

Your demo re-records itself on every release, so it always shows what your product looks like today.

- uses: vipul080/scriptcast@v0
  with:
    script: demo.yml
    start: npm run dev
    wait-on: http://localhost:3000
    commit: true
